# esplorer12
A Windows 11 browser inspired by Internet Explorer 8.1, featuring Explorer Engine, Chromium Engine and Edge Engine.
## Disclaimer

Esplorer 12 is an independent browser project inspired by the
classic Internet Explorer interface.

This project is not affiliated with, endorsed by, or sponsored by Microsoft.
It does not contain Internet Explorer source code.

Esplorer 12 uses its own project code and third-party browser technologies
where explicitly stated.
